# 版型參考（沒有使用者參考檔時才用）

每個版型都來自使用者採用或手改過的頁面，不是新設計。

## Summary 頁
Issue 橫幅（一行問題陳述）下接 3 個編號欄，每欄：編號、一行標題、一張圖、2–3 行說明。來源：使用者手改過的 summary 頁（27 個圖形、4 張圖）。

## 問題與改善對照頁
左右各一張示意圖（改前 / 改後），圖下各一行數字，底部一行結論。來源：使用者手改過的改善對照頁（436 字，原本 1036 字）。

## 狀態與時程判斷頁
時間軸加 ✘ / ● / ▲ 標記，一眼看 Option 1/2/3 的結果；Risk 與 Need Approve 寫在同頁。來源：使用者的時程評估 Roadmap 頁。

## 測試計畫頁
左邊動作示意圖（用基本圖形繪製），右邊一行文字註解，下方對應紀錄表。每頁一個測試項目。來源：使用者認可的測試計畫中文版。

## 資料表頁
標題一行，表格一張，14pt，欄位只留需要的。無副標、無色塊。來源：使用者認可的 tracker 與 gating review 表格頁。

## 8D 檢查項目頁
一個 check item 一頁，固定格式，每頁都有 comment 欄。來源：使用者對 8D 的要求。

## 不要用
- 四卡 benefits / drawbacks / schedule / open items 重複版型。
- 四格大數字 KPI 方塊加一句說明（使用者已手改掉）。
- 一頁一整面文字加 Result / Comment / Chart 三段。
